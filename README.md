# 九天智境 · Web端360°沉浸式数字展馆

《九天智境：中国式现代化中的AI力量》——昆明理工大学思想政治理论课实践教学作品（数字思政作品创作 / VR资源创作）。

以中国移动"九天大模型"为案例，围绕人工智能与产业现代化、民生现代化、社会治理现代化及青年创造力的关系展开叙事，通过纯前端的 360° 网页展馆呈现，无需任何后端或数据库，可直接部署到 GitHub Pages。

---

## 一、在线体验

部署到 GitHub Pages 后，访问：

```
https://<你的用户名>.github.io/jiutian-ai-exhibition/
```

本地预览（任选一种静态服务器）：

```bash
# 方式一
python3 -m http.server 8000

# 方式二（Node）
npx serve .
```

然后打开 `http://localhost:8000`。

> ⚠️ 不要直接双击 `index.html` 用 `file://` 打开——浏览器的跨域限制会阻止全景贴图和音视频加载，必须通过本地或线上服务器访问。

---

## 二、部署到 GitHub Pages

1. 在 GitHub 新建仓库 `jiutian-ai-exhibition`（或任意名称）。
2. 把本项目全部文件推送到仓库的 `main` 分支：

   ```bash
   git init
   git add .
   git commit -m "九天智境 · 第一版"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/jiutian-ai-exhibition.git
   git push -u origin main
   ```

3. 进入仓库 **Settings → Pages**，Source 选择 `Deploy from a branch`，分支选择 `main` / `root`，保存。
4. 等待 1–2 分钟，页面顶部会出现发布后的访问地址。

项目不依赖任何构建步骤（没有 npm / webpack），所有文件均为纯静态资源，`index.html` 就是入口。

## 三、项目结构

```
jiutian-ai-exhibition/
├── index.html                 # 网站入口：加载页 + 首页 + 展馆容器
├── css/style.css               # 全站视觉样式（玻璃拟态 / 呼吸光点 / 响应式）
├── js/
│   ├── exhibition-data.js      # 【核心配置】所有场景、热点、文案的唯一数据源
│   ├── panorama.js             # Three.js 360° 全景查看器（拖动 / 缩放 / 热点投影）
│   └── app.js                  # 应用逻辑：加载流程、场景切换、弹窗、地图、语音、全屏
├── assets/
│   ├── panorama/                # 10 张全景图（equirectangular 2:1，占位）
│   ├── video/                   # 首页背景视频 + 6 个热点视频（占位，AI生成风格）
│   ├── audio/                   # 讲解音频（待补充，见下方"占位素材清单"）
│   └── images/                  # 预留：普通图片素材
└── scripts/                     # 仅用于本地重新生成占位素材，不影响网站运行
    ├── gen_panoramas.py
    └── gen_video_posters.py
```

**如果你只需要修改文字、热点、跳转关系或替换素材路径，只需要编辑 `js/exhibition-data.js`，不需要碰 `panorama.js` / `app.js` 里的 Three.js 逻辑。**

## 五、内容与交互结构

```
首页（视频背景）
   ↓ 进入数字展馆
01 未来AI大厅 —— 世界观与主题背景
   ↓
02 九天大模型中心 —— 展馆核心，可选择三个方向
   ├── 03 产业现代化（智能制造）
   ├── 04 民生现代化（智慧健康 / 智慧教育）
   └── 05 智慧城市（社会治理现代化）
   ↓（三个方向都可返回九天中心，最终经由大厅前往）
06 青年与未来 —— 结尾空间，可重新参观
```

每个展厅至少 3–5 个热点，类型覆盖文字介绍、视频、图解（能力图谱 / 对比 / 数据可视化）、场景跳转、方向选择、创作过程展示，满足课程"每张全景图至少3个交互热点"的要求。

展馆右上角提供：**地图**（可查看六个展厅的访问进度并直接跳转）、**语音讲解开关**、**全屏**。左上角显示当前展厅序号与名称，底部显示实时探索进度。

## 六、技术说明

- 纯 HTML / CSS / JavaScript，全景渲染基于 [Three.js](https://threejs.org/)（通过 CDN 引入，`index.html` 中可见），无需打包构建。
- 全景热点为 DOM 元素，每帧根据相机投影计算屏幕位置，避免使用复杂的 3D 文字渲染，保证清晰度和可访问性（可被朗读、可键盘聚焦）。
- 素材采用相对路径，兼容 GitHub Pages 的子路径部署。
- 首屏只预加载首页背景图与第一个展厅的全景图，其余展厅素材在切换时才加载，减少首屏等待时间。
- 响应式适配：桌面端信息面板为右侧抽屉，移动端自动切换为底部抽屉；热点在触屏设备上常驻显示标签、加大点击区域。
- 无障碍：所有弹层支持 `Esc` 关闭，视频提供关闭/暂停控制，图片和音视频加载失败均有兜底展示，不会导致页面卡死或报错阻断体验。

## 七、后续工作建议

1. 用真实全景素材替换 `assets/panorama/` 下的 10 张图（建议先替换 `hall-01.jpg`，首页会优先加载它，效果最直观）。
2. 补齐 `assets/audio/` 下的六段讲解音频。
3. 用 AI 视频工具替换 `assets/video/` 下的六段视频与首页背景视频。
4. 素材到位后，建议逐个展厅走查一遍完整交互流程（拖动 → 点击热点 → 播放视频 → 切换展厅 → 打开地图），确认体验流畅后再提交。
5. 个人社会实践总结报告可结合"八、占位素材清单"中实际完成的内容进度撰写，避免虚构未完成的成果。
